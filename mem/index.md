# Project Memory

## Core
Style changes (font, color, typography, spacing) requested for a specific page — via chat OR Visual Edits — must be applied ONLY to that page. Never global, never shared components, never design tokens, unless the user explicitly says "everywhere" or "all pages".

## Memories
- [Scoped style changes](mem://preferences/scoped-style-changes) — Apply per-page styling locally (chat + Visual Edits); do not touch index.css, tailwind.config.ts, or shared UI components for one-off requests
