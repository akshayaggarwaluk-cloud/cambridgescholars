# Project Memory

## Core
Style changes (font, color, typography, spacing) requested for a specific page must be applied ONLY to that page — never globally, never to shared components or design tokens, unless the user explicitly says "everywhere" or "all pages".

## Memories
- [Scoped style changes](mem://preferences/scoped-style-changes) — Apply per-page styling locally; do not touch index.css, tailwind.config.ts, or shared UI components for one-off requests
